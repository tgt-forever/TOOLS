종합 작업 도구

TOOL 01 · EXCEL

지역 키워드

엑셀만 올리면 브라우저에서 바로 조합·변환해서 다운로드할 수 있어요. 설치가 필요 없습니다.

1

지역 × 키워드 조합 생성

지역 엑셀(A1=헤더, A2~ 지역명)과 키워드 엑셀(A1=헤더, A2~ 키워드)을 올리면, 키워드별로 열을 나눠 모든 지역과 조합한 결과 엑셀을 만들어드려요.

2

광고그룹ID 매핑

1단계 결과 파일을 열어 맨 위에 행을 하나 추가하고, 각 열에 해당 키워드의 광고그룹ID를 입력한 뒤 저장해서 여기 올려주세요. (같은 ID를 여러 열에 반복 입력해도 됩니다)
파일 구조: 1행=광고그룹ID / 2행=키워드명(원래 헤더) / 3행~=조합값

TOOL 05 · MONITOR

브랜드검색 노출 모니터링

등록한 키워드의 브랜드검색 광고 노출 상태예요. PC·모바일 버튼이 초록이면 노출, 빨강이면 미노출이에요. 광고주·키워드 등록과 알림 설정은 06 모니터링 설정 탭에서 해요.

!

모니터링 서버에 아직 연결되지 않았어요

06 모니터링 설정 탭에서 웹앱 URL과 접속 토큰을 입력하고 연결하면 여기에 현황이 나타나요.

1

노출 현황

서버 기준 - · 이 화면은 1분마다 자동으로 새로고침돼요.

네이버 검색광고 API에서 가져온 브랜드검색(시간 계약) 정보예요. 매일 06 탭에서 정한 시각에 자동 갱신되고, 노출 종료 기준일(기본 5일) 전부터 매일 만료 메일이 와요. 새 계약이 잡히면 자동으로 멈춰요.

TOOL 06 · SETTINGS

모니터링 설정

05 탭에서 감시할 광고주와 키워드를 등록하고 알림을 설정해요. 처음 한 번은 Apps Script 웹앱에 연결해야 해요 (설치 방법은 저장소의 노출모니터링_설치안내.md).

1

모니터링 서버 연결

Apps Script 웹앱 주소와 접속 토큰을 입력하세요. 이 브라우저에만 저장돼요.

2

광고주

식별 문구는 브랜드검색 광고 안에 나오는 브랜드명이나 사이트 주소예요. 이 문구가 있어야 "우리 광고주 광고"로 판정돼요. customerId는 네이버 광고시스템 오른쪽 위 계정명 옆 숫자로, 계약 기간 조회에 써요.

3

키워드

키워드 하나당 PC·모바일 각각 10분마다 1번씩 확인해요. 개인 Gmail 계정은 하루 실행 시간 제한이 있어서 키워드×매체 합계 15개 안쪽을 권장해요.
광고주키워드매체감시
4

알림 설정

같은 광고그룹에 새 계약이 잡혀 남은 기간이 이 일수를 넘으면 자동으로 멈춰요.
해당 시각부터 1시간 안에 실행돼요.
이 금액 이하이거나 예산 잠금이면 알림. 07 비즈머니 탭에서 확인해요.
