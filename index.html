종합 작업 도구

모든 파일 처리는 이 브라우저 안에서만 이뤄지며, 어떤 파일도 서버로 전송되지 않습니다.
TOOL 01 · EXCEL

지역 키워드

엑셀만 올리면 브라우저에서 바로 조합·변환해서 다운로드할 수 있어요. 설치가 필요 없습니다.

1

지역 × 키워드 조합 생성

지역 엑셀(A1=헤더, A2~ 지역명)과 키워드 엑셀(A1=헤더, A2~ 키워드)을 올리면, 키워드별로 열을 나눠 모든 지역과 조합한 결과 엑셀을 만들어드려요.

2

광고그룹ID 매핑

1단계 결과 파일을 열어 맨 위에 행을 하나 추가하고, 각 열에 해당 키워드의 광고그룹ID를 입력한 뒤 저장해서 여기 올려주세요. (같은 ID를 여러 열에 반복 입력해도 됩니다)
파일 구조: 1행=광고그룹ID / 2행=키워드명(원래 헤더) / 3행~=조합값
